# 🛍️ SmartCart AI

A modern, fully responsive e-commerce frontend built using **vanilla JavaScript**, enhanced with **AI-assisted development** and designed with a strong focus on **UI/UX, performance, and scalability**.

---

## 🚀 Live Features

### 🛒 Core Features

* Product listing with dynamic rendering
* Product details page
* Add to cart system
* Persistent cart using localStorage

### 🔍 Advanced Features

* Real-time search
* Category filtering
* Sorting (price, rating)
* Wishlist system ❤️

### 🔐 User Features

* Fake authentication (Login / Register)
* User session handling

### 💳 Checkout System

* Checkout page (mock)
* Order summary
* Pricing breakdown (subtotal, tax, shipping)

---

## 🎨 UI/UX Enhancements

* Smooth animations and transitions
* Scroll-based animations (Intersection Observer)
* Skeleton loading
* Toast notifications
* Responsive design (Mobile / Tablet / Desktop)
* Dark mode 🌙
